# yt-song-installer
Python script that uses Yt-Dlp, ImageMagick and FFmpeg to install YTmusic songs to local files

Made out of dislike to bigtechs and sheer absolute boredom

Use:

-is Installs song files

-cs Creates the finished song files

-it Installs thumbnail files

-ct Cleans up the thumbnail files

-gl Generates .lrc files for all songs that use'em

-ic Ignores the cache and regenerates EVERY song
> [!warning]
> The process does not follow the order of the parameters, instead following a set order
